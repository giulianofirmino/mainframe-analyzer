# DB2
`sql_runtime.py`, `db2_runtime.py` e `db2_cursor_runtime.py` suportam SELECT, INSERT, UPDATE, DELETE, host variables, SQLCODE 0/100, COMMIT/ROLLBACK e cursores DECLARE/OPEN/FETCH/CLOSE.
`EXEC SQL INCLUDE` é classificado como construção de compile-time no gate de fontes.
O estado DB2 participa do snapshot transacional determinístico.
